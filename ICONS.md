# Add-on Icon and Logo

To complete the Home Assistant add-on setup, you should add:

1. **icon.png** - 256x256 PNG icon for the add-on
2. **logo.png** - 256x256 PNG logo for the add-on

Place these files in the repository root directory.

You can create simple icons using:

- A Mitsubishi logo
- An MQTT bridge icon
- A Home Assistant integration icon

For now, the add-on will work without these, but they improve the visual presentation in the Home Assistant UI.
